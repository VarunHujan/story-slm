# story-slm

A comprehensive Masterclass and Practical Workspace for building a Small Language Model (SLM) from scratch.

## Project Structure
- `Course_Notes/`: Theoretical masterclass documents, historical context, diagrams, and workflows.
- `Practical_Workspace/`: The sandbox for experimental PyTorch code and manual math implementations.
- `Realtime_Backend/`: The clean, production-ready core project code.
